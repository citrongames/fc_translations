1. УПРАВЛЕНИЕ И ОБОЗНАЧЕНИЯ РУССКОЙ ВЕРСИИ
======================================================================

A       — подтвердить.
B       — отмена / выйти из разговора.
B на карте — открыть ВЕЩИ.
SELECT  — сменить активного героя, когда спутники уже присоединились.

Основные действия:
ОСМОТР  — осмотреть место/объект/персонажа.
СПРОСИ  — спросить.
ВОЗЬМИ  — взять.
ЕШЬ     — съесть.
УДАРЬ   — ударить.
КАКАЙ   — соответствующее фирменное действие игры.
РЫВОК   — таран Ури.
ВЕЩИ    — инвентарь.
ИСПОЛ.  — использовать предмет.
БРОСЬ   — выбросить/применить предмет через сюжетное действие.

Бой:
БОЙ     — обычная атака.
ПРИЁМ   — переговорные/специальные приёмы.
БЕГИ    — попытаться сбежать.
ВЕЩИ    — предметы.

Характеристики:
ОЗ = здоровье (оригинальное HP).
УМ = интеллект/опыт (оригинальное IQ).

Начало игры: примерно 30 ОЗ и 0 УМ.

======================================================================
2. СЕЗОНЫ
======================================================================

Сезон меняется с течением игрового времени. Смотри на дерево в правом
верхнем углу:

зелёное   = лето
жёлтое    = осень
белое     = зима
фиолетовое= весна

Сезоны нужны не только для декорации. Некоторые гнёзда, растения и
сюжетные события активируются лишь в определённое время. Если гайд
говорит, что объект должен быть здесь, но его нет — походи по карте и
дай сезону смениться.

3. QA ПЕРЕД СТАРТОМ — ЧТО ДОЛЖНО БЫТЬ В v0.17
======================================================================

Лучше начать холодным запуском ROM, не загружая savestate от старой версии.

Проверь:
[ ] предтитровые надписи 1989 CBS/SONY GROUP и KOJI AIHARA FANTASY;
[ ] русский мелкий текст титульника;
[ ] пункты ИГРА / ДАЛЕЕ;
[ ] экран пароля «ВВЕДИ ПАРОЛЬ»;
[ ] парольный алфавит: А Б В Г Д Е Ж З И К;
[ ] в игровом HUD белым цветом: ОЗ / УМ;
[ ] имена: СИРО / УРИ / ТЁСИ;
[ ] буква Й в слове ДАЙ печатается без мигания и превращения в Бога.

Если найдёшь баг: желательно сохранить скриншот и записать точную цепочку
действий, например «ОСМОТР -> ДАЙ -> третья страница».

======================================================================
4. НАЧАЛО — ДАЙ, БОГ И ПЕРВЫЕ СЛЕДЫ
======================================================================

Ты начинаешь рядом с бурым медведем Даем.

У Дая последовательно проверь:
ОСМОТР -> МЕСТО
ОСМОТР -> ДАЙ
СПРОСИ -> СФЕРА
СПРОСИ -> ГОРА
СПРОСИ -> ЛИЛИЯ
СПРОСИ -> ТЁСИ
ВОЗЬМИ -> ДАЙ
ЕШЬ -> ДАЙ
КАКАЙ

QA:
[ ] слово ДАЙ полностью печатается;
[ ] никакого мигания на Й;
[ ] никакой самопроизвольной смены портрета на Бога;
[ ] строки не выходят за рамку 16x3.

От Дая иди ЗАПАД, затем СЕВЕР — в пещеру к Богу.

У Бога:
ОСМОТР -> МЕСТО
ОСМОТР -> ДАЙ
СПРОСИ -> СФЕРА
СПРОСИ -> ГОРА
СПРОСИ -> ДЕМОН
СПРОСИ -> ЛЕС
СПРОСИ -> ТЁСИ
ЕШЬ -> БОГ
КАКАЙ

Последнее действие перед Богом отнимает 5 ОЗ — это нормальная шутка игры.

QA:
[ ] длинное вступление Бога полностью помещается в окно;
[ ] отображаются -5 ОЗ и остальные служебные эффекты;
[ ] портрет/анимация Бога правильные.

Выйди из пещеры и иди на один экран ВОСТОК к дереву.

ОСМОТР -> МЕСТО
ОСМОТР -> НОРА
ОСМОТР -> ЦВЕТ.
ВОЗЬМИ -> ЦВЕТ.

Попытайся выйти кнопкой B, затем снова используй ОСМОТР / СПРОСИ / ЕШЬ.
Появится зверёк, связанный с Момо.

ОСМОТР -> зверёк
СПРОСИ -> ТЁСИ
ДА

После сцены иди ЮГ мимо Дая, ещё два экрана ЮГ и затем ВОСТО к реке.
Найди следы:

ОСМОТР -> МЕСТО
ОСМОТР -> СЛЕД

Дальше последовательно двигайся СЕВЕР и проверяй появляющиеся следы.
Новые следы становятся активны только после предыдущих.

После падения тануки вернуться к первым следам и дити на зпад, снова по следам и в итоге к семье медведей (см. ниже)

5. ПЕРВЫЕ ПОБОЧНЫЕ ТОЧКИ УМ
======================================================================

По дороге есть несколько необязательных, но очень полезных +25 УМ.
Для QA лучше сделать их все: они проверяют системные сообщения.

5.1. Пещера со стариком/родником
--------------------------------
В южной части маршрута найди пещеру:

ОСМОТР -> МЕСТО
ОСМОТР -> РОДН.
ОСМОТР -> СТАР.
СПРОСИ -> СТАР.
СПРОСИ -> БОГ Ж.

5.2. Камень в болотистой реке
-----------------------------
В восточной болотистой части:

ОСМОТР -> МЕСТО
ОСМОТР -> РЕКА
ОСМОТР -> КАМЕН
ВОЗЬМИ -> КАМЕН

Должно быть +25 УМ.

5.3. Облака у океана
--------------------
В крайней северо-восточной части возле океана найди травяной участок.

ОСМОТР -> НЕБО
затем несколько раз ОСМОТР -> ОБЛАК

Одно из наблюдений даёт +25 УМ.

6. МАМА, СИРО И ЧЕТЫРЕ ЦВЕТА КАКАШЕК
======================================================================

Вернись на запад к семье медведей. Поговори с мамой несколько раз и с
Ури. В определённый момент управление переключится на Ури.

Иди к пляжу на северо-востоке и найди Сиро.

ОСМОТР -> МЕСТО
ОСМОТР -> СИРО
ОСМОТР -> МОРЕ
ОСМОТР -> РЫБА
СПРОСИ
ОСМОТР -> СИРО
ОСМОТР -> РЫБА

Последний осмотр рыбы даёт +25 УМ.

Попытайся уйти и затем вернись к маме возле стартовой области.

СПРОСИ -> МАМА (дважды)
ОСМОТР -> КРАСН
ВОЗЬМИ -> КРАСН

Отсюда начинается сбор цветных какашек для сюжетного механизма.

6.1. Красная
------------
Иди на два экрана ВОСТОК и затем СЕВЕР в пещеру.

ВЕЩИ -> КРАСН -> ИСПОЛ.
КАКАЙ

Вернись к маме:
СПРОСИ -> ТЁСИ
СПРОСИ -> КАКА

6.2. Белая
----------
Иди на ЮГ, затем на ЗАПАД вдоль реки, перейди её. Возле экрана с тремя
камнями спустись ЮЖНЕЕ и затем ЗАПАДНЕЕ в подозрительную пустую область.

ОСМОТР -> БЕЛ
ВОЗЬМИ -> БЕЛ

6.3. Сова
---------
Отсюда два экрана ЮГ — сова.

СПРОСИ -> СОВА
СПРОСИ -> СФЕРА
СПРОСИ -> ГОРА
СПРОСИ -> ДЕМОН
СПРОСИ -> ТЁСИ
УДАРЬ -> СОВА

6.4. Жёлтая
-----------
Пройди к проходу между двумя горами, где между ними стоит дерево.

ОСМОТР -> ЖЁЛТ
ВОЗЬМИ -> ЖЁЛТ

6.5. Чёрная
-----------
Сделай шаг назад на юг, затем ВОСТОК и СЕВЕР.

ОСМОТР -> ЧЕРН
ВОЗЬМИ -> ЧЕРН

======================================================================
7. СКРЫТЫЙ КАШТАН И ЗАКАТ
======================================================================

7.1. Каштан
-----------
От чёрной какашки двигайся по линейной дорожке: ВОСТОК -> ЮГ -> ВОСТОК
-> СЕВЕР. На втором ряду снизу ищи промежуток между деревьями примерно
в шести клетках от левого края. Внешне клетка обычная.

ОСМОТР -> КАШТ.
ОСМОТР -> КОЛЮЧ
ЕШЬ -> КОЛЮЧ
ВОЗЬМИ -> КОЛЮЧ
УДАРЬ -> КАШТ.
ВОЗЬМИ -> КОЛЮЧ
ЕШЬ -> КОЛЮЧ

Получишь +25 УМ.

7.2. Закат
----------
Вернись на запад по линейной дороге. На поляне: ЮГ -> ЗАПАД -> СЕВЕР
дважды, затем иди ВОСТОК до океана. У края воды спустись на ЮГ на
специальную клетку.

Несколько раз:
ОСМОТР -> МЕСТО
затем:
ОСМОТР -> ЗАКАТ

Один из осмотров даёт +25 УМ.

К северу/западу от этого места вскоре появится пространственное
искажение. ОСМОТР -> МЕСТО.

8. УРИ, МЕШОК И МОСТ ИЗ ДЕРЕВА
======================================================================

От искажения иди ЗАПАД дважды, ЮГ, ЗАПАД, ЮГ. Найдёшь Ури.

ОСМОТР -> МЕСТО
ОСМОТР -> УРИ
ОСМОТР -> МЕШОК
СПРОСИ -> УРИ
ВОЗЬМИ -> МЕШОК
УДАРЬ -> УРИ

Ури получает +25 УМ.

Затем двигайся СЕВЕР, ВОСТОК, СЕВЕР и дальше к дереву под искажением.

ОСМОТР -> МЕСТО
ОСМОТР -> ДЕР.
УДАРЬ -> ДЕР.
SELECT -> УРИ
РЫВОК

Дерево падает и образует мост.

Отсюда: ВОСТОК x2, СЕВЕР примерно x5, ВОСТОК x2 — снова пещера.
Используй три собранных цвета:

ВЕЩИ -> ЧЕРН -> ИСПОЛ.
ВЕЩИ -> БЕЛ  -> ИСПОЛ.
ВЕЩИ -> ЖЁЛТ -> ИСПОЛ.

Сюжет объединит компанию.

QA:
[ ] SELECT правильно меняет СИРО / УРИ / ТЁСИ;
[ ] имена в HUD белые;
[ ] интерьеры используют русский шрифт.

9. ПЛАТО, МАМА, ОБЕЗЬЯНЫ И ЧЕРЕПАХА
======================================================================

От пещеры иди к стене на ЗАПАД, затем три экрана ЮГ. В центре квадрата
между четырьмя холмами активируется сцена.

ОСМОТР -> МЕСТО
ОСМОТР -> СИРО
ОСМОТР -> ТЁСИ
SELECT -> ТЁСИ
ОСМОТР -> СИРО (дважды)
ОСМОТР -> УРИ
SELECT -> СИРО
ОСМОТР -> УРИ (дважды)
ОСМОТР -> ТЁСИ
СПРОСИ -> УРИ

Одна из реплик даёт +25 УМ.

Дальше иди ЮГ к реке, через мост на ЗАПАД, один экран ЮГ и затем примерно

ОСМОТР -> МЕСТО
ОСМОТР -> УТЁС
ОСМОТР -> МАМА
СПРОСИ -> МАМА (несколько раз; после сцены продолжи спрашивать)

Войди в пещеру и выйди через другие ступени на плато.

ОСМОТР -> ОБЕЗ.
СПРОСИ -> СФЕРА (дважды)
ДА

1) ОБЕЗ1
2) ОБЕЗ2
3) ОБЕЗ4
4) ОБЕЗ3
5) ОБЕЗ3
6) ОБЕЗ4

-------------

ОСМОТР -> ЧЕРЕП
СПРОСИ -> ЧЕРЕП -> СФЕРА

9.3. Летяга
-----------

ОСМОТР -> МЕСТО

СПРОСИ -> ЧЕРЕП

СПРОСИ

ОСМОТР -> МЕСТО

СПРОСИ

10.2. Улей и злой медведь
-------------------------
На юго-востоке найди сердитого медведя:
ОСМОТР -> МЕСТО

ВЕЩИ -> УЛЕЙ -> ИСПОЛ.

Получишь +25 УМ и по завершении цепочки — ОСЕННЮЮ СФЕРУ.

[ ] все динамические +25 УМ показываются числами, а не мусором.

11. ЛЕТУЧАЯ МЫШЬ, ПЕЩЕРА И ПЛОТ
======================================================================

Спустись по ступеням, затем ЗАПАД и ЮГ — летучая мышь.

ОСМОТР -> МЫШЬ

КАКАЙ
ВОЗЬМИ -> МЫШЬ

ОСМОТР -> МЕСТО
ВЕЩИ -> МЫШЬ -> ИСПОЛ.
КАКАЙ

ОСМОТР -> МЕСТО

ОСМОТР -> МЕСТО

РЫВОК

12. МОРЕ, РАКУШКИ И ЛЕТНЯЯ СФЕРА
======================================================================

На бревне оставайся в воде. Плыви ВОСТОК, СЕВЕР, ВОСТОК — в реку,
впадающую в ледяной континент.

ОСМОТР -> МЕСТО
ОСМОТР -> ВОДОП.
УДАРЬ

14.1. Первичная прокачка
-----------------------
От старта двигайся ЮГ к кишечноподобным ходам. Бей бирюзовых змей — они
слабые. Качайся, пока не появится примерно пятый переговорный ПРИЁМ
(ОБХВАТ — хороший ориентир).

Побеждённые враги иногда дают ГЛЮК. — лечебный предмет. В инвентаре
количество может отображаться неочевидно, поэтому не трать всё подряд.
Старик у начала также может лечить.

14.2. Более сильные враги и экипировка

После прокачки иди через средний из трёх южных путей ещё на экран ЮГ,
затем по юго-западной ветке. Здесь шестирукие клетки заметно сильнее.
В сундуках могут быть БРОНЯ и ЩИТ.

Практический ориентир для комфортного продвижения: около 300 УМ.
Если Сиро постоянно промахивается/не наносит урон — докачайся.

26. ПАРОЛЬ — ОБЯЗАТЕЛЬНАЯ QA-ПРОВЕРКА
======================================================================

В русской версии парольная система логически осталась оригинальной:
внутри игра хранит десятичные значения 0-9, но показывает их русскими
буквами:

0 = А
1 = Б
2 = В
3 = Г
4 = Д
5 = Е
6 = Ж
7 = З
8 = И
9 = К

Когда игра ВЫДАСТ пароль:
1. сфотографируй/запиши его точно;
2. сделай холодный Reset или перезапусти ROM;
3. на титульнике выбери ДАЛЕЕ;
4. введи ту же последовательность русских букв;
5. проверь, что восстановилось ожидаемое состояние.

Это одна из самых важных проверок перевода — она проверяет и генерацию,
и отрисовку, и ввод, и обратное преобразование символов в цифры.

======================================================================
27. ЧТО ОСОБЕННО ЛОВИТЬ ПРИ QA
======================================================================

1. Любая буква, которая вызывает эффект вместо печати.
   Ранее Й конфликтовала с управляющим кодом; это исправлено.

2. Текст за рамкой.
   Обычное диалоговое окно: максимум 16 символов x 3 строки на страницу.

3. Действия длиннее 6 клеток.

4. Неправильный CHR-шрифт в новой локации.
   Если внезапно снова японские глифы — сделай скрин и укажи локацию.

5. Неверный цвет букв.
   HUD должен быть белым.

6. Динамика боя:
   имя врага, число урона, награда УМ, предметы после боя.

7. Портреты/спрайты.
   Если при тексте персонаж внезапно превращается в другого — записать
   точное действие и слово, на котором это случилось.

8. Сезонные события.

9. Все четыре сферы и выдача экипировки.

10. Пароль.

11. Концовка и титры.

======================================================================
28. НЕОБЯЗАТЕЛЬНО: ЧИТ ДЛЯ ЧИСТО ТЕХНИЧЕСКОГО ТЕСТА
======================================================================

В старом community walkthrough указан RAM-чит:
001E = FF
