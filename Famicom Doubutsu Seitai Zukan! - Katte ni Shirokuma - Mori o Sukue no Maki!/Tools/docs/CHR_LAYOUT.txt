KATTE NI SHIROKUMA — CHR / GRAPHICS LAYOUT
===========================================

FINAL iNES header: PRG=16 x 16 KiB, CHR=16 x 8 KiB.
Поэтому начало CHR в FINAL:
  16 + 16*$4000 = file $40010

В исходной японской ROM PRG=8, поэтому CHR начинался с $20010.
Инструменты extract_chr.py/insert_chr.py вычисляют адрес автоматически из iNES
header и одинаково работают с original и FINAL.

Каждый 8 KiB CHR bank = 512 тайлов NES 8x8, 2 bpp.
PNG по умолчанию: 16 тайлов в строке, 32 ряда = 128x256 px.
Значения яркости 0/85/170/255 кодируют индексы пикселя 0/1/2/3.

Основной текстовый шрифт в ходе проекта дублировался в нескольких игровых CHR
банках (исторически 8 KiB banks 2,3,4,5,6,7,12). Кроме того HUD и password UI
используют отдельные CHR-представления/подбанки, поэтому глобально менять один
тайл и ожидать одинаковый эффект во всей игре нельзя.

Для безопасного редактирования:
1. Extract нужного банка.
2. Изменяй только нужные 8x8 тайлы.
3. Не меняй размер PNG и порядок тайлов.
4. Insert обратно в ТОТ ЖЕ bank.
5. Запусти validate_final.py --allow-modified и проверь экран в эмуляторе.
