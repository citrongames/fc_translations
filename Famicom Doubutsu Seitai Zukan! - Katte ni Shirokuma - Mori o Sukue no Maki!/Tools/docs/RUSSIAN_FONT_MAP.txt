Служебная пунктуация:
$B2 = 「
$B4 = - / —
$B6 = !
$B7 = ?
$BB = .
$F2-$FB = 0-9
$FF = space

Управляющие коды (не глифы):
$01 = {ED}
$02 = {FACE02}
$03 = {FACE03}
$04 = {FACE04}
$89 = {LN}
$B3 = {NEXT}

Особенность: uppercase Й перенесена на $FD, потому что прежний кандидат $B8
является игровым effect command. Это исправляет эффект/мигание в слове ДАЙ.
