БЫСТРАЯ СБОРКА
--------------
Требуется Python 3 и Pillow.

Установка зависимости:

  python -m pip install -r requirements.txt

Сборка:

  python build_russian_rom.py \
    "Murder Club - Honkaku Mystery Adventure (Japan).nes" \
    -o Murder_Club_RU_FINAL.nes

Проверка данных перевода:

  python validate_translation.py

Проверка готового ROM:

  python verify_built_rom.py Murder_Club_RU_FINAL.nes


ЧТО ДЕЛАЕТ BUILDER
------------------
1. Проверяет SHA1 исходного японского ROM.
2. Патчит статический интерфейс.
3. Сохраняет исходные позиции 00 в таблицах вариантов выбора.
4. Для рамочных списков использует 10 текстовых знакомест;
   при наличии дополнительной японской byte-capacity ставит $FD после
   10-го знакоместа, не ломая индексацию вариантов.
5. Удаляет хардкодное японское てん после счётчиков/статистики.
6. Перепаковывает четыре последовательных текстовых пула в новые MMC3 банки.
7. Расширяет PRG с 128 KiB до 256 KiB.
8. Патчит дополнительные/короткие текстовые фрагменты.
9. Патчит две совместимые прямые копии финальных строк.
10. Патчит настоящий отдельный 184-байтовый блок финального эпилога
    по PRG $02B98.
11. Встраивает финальный русский основной шрифт.

ВАЖНЫЕ ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ
------------------------------
1. Нельзя ориентироваться на исходную японскую byte-capacity как на
   визуальную ширину строки. Японские дакутены занимают дополнительные
   байты, но не дополнительные экранные знакоместа.

2. Основное диалоговое окно реально имеет ширину 26 и высоту 4 строки.

3. Компактные таблицы вариантов читаются игрой последовательно по
   исходным 00-терминаторам. Эти терминаторы нельзя переносить.

4. Правый край рамки располагается после 10 текстовых знакомест.
   Именно поэтому ранние экспериментальные варианты с новым 00 или $FD
   внутри 10-го знакоместа ломали либо список, либо геометрию рамки.

5. Финальный эпилог существует отдельной третьей копией:
     ROM file offset $02BA8
     PRG offset      $02B98
     размер          184 байта
   Обычная перепаковка диалогов его не затрагивает.

6. Парольный шрифт — отдельная CHR-область. Его нельзя перерисовывать
   вместе с основным русским шрифтом. Финальная игра проверена:
   система паролей работает.
