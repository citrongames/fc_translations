OKHOTSK RU v0.8.21 — BLACKJACK / NUMERIC FIX
================================================

Симптомы
--------
1. Имя игрока на экране карт отображалось с нигори/дакутэном и меняло строчные буквы.
2. Имя соперника сверху оставалось японским シュン.
3. Вместо числа ставки появлялось слово вроде «Продавщица».
4. В финале партии динамические числа могли превратиться в «--»/длинный мусорный текст.

Причины
-------
Карточная мини-игра использует несколько отдельных старых японских механизмов, не общий диалоговый UI.

Имя игрока:
CPU $F5A7-$F5C8 читает имя из $4B-$4E и считал любой байт >=$40 каной с дакутэном.
Русские строчные находятся в диапазоне $41-$5F. Порог изменён $40->$F0. $FF проверяется раньше,
поэтому терминатор не затрагивается.

Числа:
Оригинальный текстовый handler D0-D9 преобразовывал код D0+n в тайл $74+n.
Начиная с RU v0.8 диапазон D0-EF используется вторичным BPE-словарём. Поэтому сырой D1 уже
не означает цифру 1, а вызывает словарную запись. Исправление:
- [GLYPH:$D0..$D9] -> прямые RU digit codes $22..$2B;
- [DICT:$Dx] остаётся словарным токеном;
- уже собранная v0.8.20 содержит 45 живых таких маркеров — все заменены;
- formatter CPU $F9AC для [FD:$00]/[FD:$01] также переведён с D0-D9 на $22-$2B.

Статика экрана:
PRG $00934-$00936: 47 71 6E (シュン) -> 13 20 0F (СЮН).

Ставка:
Оригинал «Nまいですね» относится к выбранному числу фишек. Русский shared EC37 теперь:
«N фиш.» / «Теперь тяну я.» вместо ошибочного «N-я карта».
