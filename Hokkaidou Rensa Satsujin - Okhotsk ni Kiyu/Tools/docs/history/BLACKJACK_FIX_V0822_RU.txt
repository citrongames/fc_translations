OKHOTSK RU v0.8.22 — BLACKJACK LOSS + DIGIT 0
================================================

1. Непереведённая строка после полного проигрыша
------------------------------------------------
В v0.8.21 ID1353 был уплотнён post-build hotfix-ом. В его конец ошибочно вернулась
жёсткая ссылка F2:$EC53 из исходного workfile. После repack остальные карточные
shared-потоки уже были релокированы, но $EC53 оставался оригинальным японским:

  シュン「さあ そうさを ぞっこうしましょう！

Поэтому после статистики проигрыша появлялся японский текст. В v0.8.22 поток
$EC53 локализован в пределах исходных 17 байт:

  Сюн:Продолжим
  расследование!

Соседние карточные F2 проверены по реальным runtime-целям:
- ID1337 -> ECFF + ED1A: RU / RU
- ID1338 -> ECF0 + ED1A: RU / RU
- ID1353 -> EC53: RU

2. Новый тайл цифры 0
----------------------
Пользовательский sprite_0.bmp преобразован в NES 2bpp tile:

  3C 46 4A 4A 52 52 62 3C  00 00 00 00 00 00 00 00

Он записан в два слота главного CHR-шрифта:
- $22 — прямая русская цифра 0 (сценарий / dynamic decimal);
- $74 — исходный legacy/password numeric glyph.

Это гарантирует одинаковый 0 при выдаче пароля и на экране ввода.
prepare_ru_font_v08.py также закрепляет этот тайл при будущей пересборке шрифта.
