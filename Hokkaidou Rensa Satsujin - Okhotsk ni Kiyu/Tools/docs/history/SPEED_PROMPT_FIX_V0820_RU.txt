Okhotsk RU v0.8.20 — speed prompt fix
====================================

Симптом
-------
После загрузки пароля / CONTINUE экран «Какую скорость текста выбрать?» ломался:
часть текста появлялась уже поверх специального меню БЫС / НОР / МЕД.

Причина
-------
Общий reflow v0.8.19 ограничивал обычный диалог тремя строками и вставил
[F1:$0A][FE][F9] внутрь root ID 6 и ID 7:

  Какую скорость текста [PAGE] выбрать?

Для обычного диалога это корректная новая страница. Но эти root-записи особые:
сразу после их завершения движок открывает отдельный системный экран выбора скорости.
[FE] передавал управление этому экрану, а оставшееся «выбрать?» выводилось поверх него.

Исправление
-----------
ID 5:
  Куроки:[F3],верно?
  [F1:$02]Скорость текста?

ID 6:
  Куроки:[F3],с возвращением.
  [F1:$02]Продолжим расследование.
  [F1:$02]Скорость текста?

ID 7:
  Сюн:[F3],с возвращением.
  [F1:$02]Продолжим расследование.
  [F1:$02]Скорость текста?

Все три помещаются в безопасные три строки и не содержат PAGE до системного меню.

Защита от регресса
-------------------
- reflow_dialogue_ru.py: SYSTEM_ROOT_OVERRIDES для ID 5/6/7;
- check_dialogue_layout.py: PAGE внутри этих ID = ошибка;
- verify_full_rom.py: проверяет точные закодированные потоки ID 5/6/7;
- patch_speed_prompt_ru.py: безопасно исправляет уже собранную v0.8.19 in-place.

Проверка suffix-sharing
-----------------------
Для старых диапазонов ID 5/6/7 проверены все root pointers и F2 targets.
Ни один другой поток не указывает внутрь перезаписываемых диапазонов, поэтому
in-place patch не повреждает suffix-shared строки.
