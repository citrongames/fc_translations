OKHOTSK RU — РАЗБОР БАГА С СЕРЫМИ БУКВАМИ (v0.8.12)

Сравнивались FCEUX save states одного момента:
- оригинальная ROM;
- русский перевод v0.8.12.

Результат:
1. PRAM ($20 байт палитры) в обоих состояниях совпадает побайтово.
2. В оригинале нижняя часть nametable attribute table остаётся нулевой.
3. В v0.8.12 в attribute bytes $23E5+ попадает последовательность, совпадающая с русской строкой первой post-intro заставки.
4. Источник найден в ROM: CPU $D913 содержит 64-байтную таблицу, которую код напрямую копирует в PPU $2007.
5. v0.8.12 ошибочно считала нулевой хвост этой таблицы ($D938) свободным ROM-space и записала туда 22 тайла «ЛОГИНСОФТ ПРЕДСТАВЛЯЕТ».
6. После загрузки соответствующей сцены эти байты становились атрибутами палитры; поэтому отдельные 2x2 tile-квадранты текста становились серыми.

Исправление v0.8.17:
- никаких изменений F9/очистки/PPU renderer;
- таблица $D913-$D952 восстановлена и защищена verifier-ом;
- первая заставка остаётся на штатном $EC8B (18 tiles) как «ЛОГИНСОФТ ПРЕДСТ.»;
- вторая заставка остаётся полной: «ДЕТЕКТИВ ЮДЗИ ХОРИИ».
