OKHOTSK FC — ИСТОЧНИКИ ДЛЯ ЛОКАЛИЗАЦИИ
==============================================

Приоритет:
1) извлечённый FC ROM/script_work.txt;
2) оригинальный FC-мануал / его транскрипция;
3) официальные материалы Nintendo / G-MODE о 1987-части;
4) FC-ориентированные справочники/гайды — для проверки чтений и контекста;
5) сторонние пересказы — только как подсказка, не как источник истины.

1. Транскрипция руководства Famicom
   «オホーツクに消ゆ ～げーむのせつめいしょ（仮）～（ファミコン編）」
   https://setsumei.cloudfree.jp/famicom/okhotsk/okhotsk.html
   Использовано: пролог, основные персонажи, 14 команд, имя 4 знака,
   система «そうさメモ»/пароля.

2. Nintendo Topics, 12.09.2024
   «あの「オホーツクに消ゆ」が……今、甦る。…»
   https://www.nintendo.com/jp/topics/article/56913b9f-0751-4c93-9c26-1674af735c02
   Использовано: официальное описание 1987-сюжета и главных персонажей; подтверждение
   роли героя (警視庁の警部), Куроки, Сюна, Макико (19 лет), Мэгуми.

3. G-MODE — история создания, глава 5
   «生誕秘話第五章 白夜に消えなかった『オホーツク』»
   https://info.gmodecorp.com/cs/okhotsk/birthstory5/
   Использовано: подтверждение, что при переносе на Famicom сценарий сильно
   переработали; Макико расширили, для неё добавили подругу; текст/графику сжимали.

4. GCGX — персонажи
   https://gcgx.games/okhotsk/character.html
   Проверка FC/ремейк-биографий основных героев. Важное замечание: имя главного
   героя «Нитта Тэцудзи» в самой FC-версии не показывается; игрок задаёт имя.

5. GCGX — титры FC
   https://gcgx.games/okhotsk/ending.html
   Использовано: латинские формы/чтения SARUWATARI SYUNSUKE, NOMURA MAKIKO,
   NAKAYAMA MEGUMI, MASUDA BUNKICHI, IIJIMA YUKIO, SHIRAKI YUKUROU,
   OKUMURA KISUKE, AKUTSU HIDEO, NOMURA GENJI.

6. GCGX — системная информация
   https://gcgx.games/okhotsk/info.html
   Проверка имени 1–4 знака, Continue/пароля и базовой схемы управления.

7. GCGX — FC walkthrough
   https://gcgx.games/okhotsk/chart.html
   Используется только для последовательности расследования/контекста сцен.

ОСОБАЯ ОГОВОРКА
----------------
Старая транскрипция мануала пишет имя жены Масуды как «増田たみ». Сам FC ROM в
реплике персонажа содержит «ますだ たえ». Для перевода выбрано «Таэ Масуда».

Сюжетные спойлеры в STORY_REFERENCE_RU.txt сверены прежде всего с самим извлечённым
FC-скриптом (в частности ID 1167, 1184, 1265–1276), а не с пересказами.
