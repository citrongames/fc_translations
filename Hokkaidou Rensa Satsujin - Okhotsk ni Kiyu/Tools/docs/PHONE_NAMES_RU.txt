OKHOTSK RU — ТАБЛИЦА ФАМИЛИЙ НЕВЕРНЫХ ТЕЛЕФОННЫХ НОМЕРОВ
=============================================================
Версия: v0.8.8

ЧТО ЭТО
-------
В text bank A по адресу $0E4E-$0E7F находится отдельная таблица 50 байт:
10 слотов по 5 байт. Это НЕ обычные root/F2-реплики сценария.

Оригинальные фамилии:
  すずき / さとう / やまだ / たなか / なかむら /
  いとう / もりた / ふじた / きむら / さわだ

Таблица используется для случайных ответов при звонке по неверному номеру.
Эти люди не являются сюжетными персонажами, их фамилии не являются уликами и
запоминать их для прохождения не требуется.

ПОЧЕМУ НЕ БУКВАЛЬНАЯ ТРАНСЛИТЕРАЦИЯ
------------------------------------
Каждый слот имеет ровно 5 байт и обязан содержать FF-терминатор, поэтому для
фамилии остаётся максимум 4 однобайтовых русских глифа. Например СУЗУКИ,
ТАНАКА, НАКАМУРА и КИМУРА физически не помещаются без изменения логики таблицы.

Поскольку это намеренно безымянные посторонние абоненты, в русском патче
используются другие реальные короткие японские фамилии. САТО и ИТО сохранены
из оригинального набора, поскольку они помещаются без сокращения.

Оригинал -> русский экран
-------------------------
  すずき   -> КАТО
  さとう   -> САТО
  やまだ   -> АБЭ
  たなか   -> ОДА
  なかむら -> АОКИ
  いとう   -> ИТО
  もりた   -> МОРИ
  ふじた   -> ХАРА
  きむら   -> ОНО
  さわだ   -> КУБО

ТЕХНИКА
-------
Text offset: $0E4E
PRG-relative: $28E4E
Размер: 10 * 5 = 50 байт

Патчер:
  tools/patch_phone_names_ru.py

build_project.py запускает его автоматически после patch_static_ui_ru.py.
verify_full_rom.py проверяет все 50 байт итоговой таблицы.
selftest.py проверяет исходную японскую таблицу и русский патч.
