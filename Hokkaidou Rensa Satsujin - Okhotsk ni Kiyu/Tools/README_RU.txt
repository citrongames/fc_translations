ПРИМЕЧАНИЕ ДЛЯ SAVE STATE
-------------------------
Save state эмулятора хранит RAM/CHR/nametable. Поэтому старый .fcs, созданный на
предыдущей тестовой версии, может визуально сохранить уже нарисованный старый
экран. Для чистой проверки специальных экранов лучше открыть их заново либо
использовать обычный игровой пароль.

ИНСТРУМЕНТЫ
-----------
Финальный source/project template находится в project_template/.
Основная команда проверки готовой ROM:
  python3 tests/verify_full_rom.py Okhotsk_RU_v0.8.23_FINAL.nes

Проверка геометрии диалогов:
  python3 tools/check_dialogue_layout.py project_template/script_work.txt \
      --shared-translations project_template/shared_translations_full.json

Сборка из поддерживаемой чистой японской ROM:
  python3 tools/build_project.py game.nes project_template/script_work.txt \
      --ru-bpe project_template/ru_bpe.tsv \
      --shared-translations project_template/shared_translations_full.json \
      -o Okhotsk_RU_rebuilt.nes

Подробности: docs/MANUAL_RU.txt
